# Overview

Project Schedules are great for one project. Activity Tracker is for looking across many projects at once, with activity columns grouped under each Activity Template.

# Convert to Activity Tracker

Choose one or more Project Templates, pick the Enhanced Activity fields that become columns, and create the Activity Tracker.
